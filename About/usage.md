# 使用方法

## 快速开始

1. 启动程序后，系统托盘出现程序图标
2. 右键托盘图标，选择「开始监听」
3. 在弹出窗口中选择触发方式和配置档案，点击「开始」
4. 按下隐藏热键（默认 `Ctrl + Alt + Q`），浏览器窗口即刻隐藏
5. 按下还原热键（默认 `Ctrl + Alt + F9`），窗口恢复

## 自定义配置

右键托盘图标 →「用户设置」进入配置界面：

- **热键修改**：点击虚拟键盘上的按键组合自定义隐藏 / 还原快捷键
- **应用名称**：输入目标浏览器的进程名（如 `msedge.exe`），支持点击按钮自动填入
- **个性化设置**：调整自动暂停、暂停方式、热区高亮时长、热区位置与大小

修改后点击「保存」即可生效。新建的配置档案可通过顶部下拉栏快速切换。

## 触发方式

| 方式 | 说明 |
|------|------|
| 快捷键 | 通过全局热键触发，适合键盘操作习惯 |
| 鼠标 | 屏幕指定位置鼠标点击触发 |

触发方式在启动时选择，写入 `save.json`，下次启动默认使用上一次的选择。
