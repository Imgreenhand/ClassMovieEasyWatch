# 使用方法

## 快速开始

1. 启动程序，系统托盘出现图标
2. 右键托盘图标 →「开始监听」
3. 在弹出的开始窗口中选择触发方式和配置档案 → 点击「开始」
4. 按下隐藏热键（默认 `Ctrl + Alt + Q`），浏览器窗口即刻隐藏
5. 按下还原热键（默认 `Ctrl + Alt + F9`），窗口恢复

## 自定义配置

右键托盘图标 →「用户设置」进入配置界面：

- **热键修改**：点击虚拟键盘上的按键组合，自定义隐藏/还原快捷键
- **应用名称**：输入目标浏览器的进程名（如 `msedge.exe`、`chrome.exe`），支持快捷按钮一键填入
- **个性化设置**：自动暂停、暂停方式、热区预览（可拖拽调整位置和大小）、高亮时长

修改后点击「保存」→ 下次触发隐藏/还原时自动生效，无需重启监听。

## 触发方式

| 方式 | 说明 |
|------|------|
| 快捷键 | 全局热键触发，适合键盘操作 |
| 鼠标 | 屏幕指定位置点击触发 |

触发方式和配置档案在启动时选择，写入 `save.txt`，下次启动默认使用上次的选择。
