# 功能说明

## 核心功能

### 窗口隐藏与还原

通过热键或屏幕边缘浮动按钮触发，瞬间隐藏目标浏览器窗口并静音。再次触发即可还原窗口、恢复音量。

### 编排执行

隐藏流程按序执行：查找窗口 → 自动暂停 → 隐藏窗口 → 静音。还原流程反向：还原窗口 → 恢复音量 → 自动暂停。状态机防抖，避免误触。

### 配置热加载

通过设置界面修改配置后保存，核心逻辑下次执行时自动读取最新配置，无需重启程序。

### 自动暂停

支持两种暂停方式：

- **WM_APPCOMMAND**（推荐）：精准发送到目标浏览器窗口
- **全局媒体键**：模拟键盘媒体暂停键（备用方案）

### 多配置档案

支持创建多套配置档案，每套可独立设置热键、目标浏览器、热区位置等参数。

## 辅助功能

- **屏幕边缘热区**：透明触发区域，鼠标点击即可触发隐藏/还原，位置和大小可拖拽调整
- **系统托盘**：程序最小化到托盘，右键菜单快速操作
- **预飞检查**：启动时检测音频设备和浏览器进程，异常时降级运行并提示
