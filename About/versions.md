# 版本管理

ClassMovieEasyWatch 的版本通过 [GitHub Releases](https://github.com/Imgreenhand/ClassMovieEasyWatch/releases) 管理。

## 获取最新版本

```bash
git clone https://github.com/Imgreenhand/ClassMovieEasyWatch
cd ClassMovieEasyWatch
git pull origin main
```

或直接下载最新版本：[Releases 页面](https://github.com/Imgreenhand/ClassMovieEasyWatch/releases)

## 更新日志

### v0.1.0 (2026-07)

- 初始版本发布
- 支持热键隐藏 / 还原浏览器窗口
- 支持 WM_APPCOMMAND 和全局媒体键两种暂停方式
- 多配置档案管理
- 屏幕边缘热区触发
- 系统托盘集成
- 浮动按钮触发方式
- 关于页面与版本管理
